# Superday Brief

A free daily market briefing for students recruiting for finance roles: the most important stories of the day, ranked, with a 60-second market view and interview talking points.

- `index.html` — the site
- `editions/` — one JSON file per day (`YYYY-MM-DD.json`) plus `index.json`, the list of editions newest first

Editions are updated automatically before the open and after the close on weekdays, and on Sunday afternoons.
